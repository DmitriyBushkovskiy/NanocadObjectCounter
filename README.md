# NanocadObjectCounterPlugin

Плагин для [nanoCAD](https://nanocad.ru/), позволяющий определить количество объектов на чертеже: объектов выбранного типа или объектов всех типов.

Проверка работоспособности плагина выполнялась на `nanoCAD x64 25.0`.

## Работа с плагином

1. Откройте чертёж.
2. Загрузите `NanocadObjectCounterPlugin.dll`:
   **Настройки → Приложения → Загрузка .NET приложения**.
3. В командной строке введите:

   ```text
   COUNTOBJECTS
   ```

4. Выберите объект для поиска примитивов соответствующего типа, или нажмите `Enter` для определения количества объектов всех существующий на чертеже типов.
5. Результат работы команды будет выведен в командной строке.

Для объектов заданного типа:

`Найдено объектов типа Line: 3 шт.`

Для всех объектов:

```
Найдено объектов: 9 шт. Следующих типов:
Line: 3 шт.
Circle: 2 шт.
Viewport: 4 шт.
```
